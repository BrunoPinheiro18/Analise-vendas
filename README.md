# 📊 Análise Exploratória de Dados de Vendas

## Descrição
Análise exploratória de um dataset real com 2.823 transacções de vendas 
internacionais, utilizando Python, Pandas, Matplotlib e Seaborn.

## Objectivos
- Identificar os produtos com maior receita
- Analisar a sazonalidade das vendas ao longo do ano
- Mapear os mercados geográficos mais rentáveis

## Principais Insights
- 🥇 **Classic Cars** gera ~40% da receita total ($3.9M)
- 📅 **Novembro** é o mês de pico de vendas (Black Friday)
- 🌍 **EUA** domina com mais receita do que todos os outros países juntos

## Ferramentas utilizadas
- Python 3
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Como executar
1. Clona o repositório
2. Instala as dependências: `pip install pandas matplotlib seaborn`
3. Abre o ficheiro `.ipynb` no Jupyter Notebook
